# 亚洲国家与首都地图记忆手册

在线阅读：<https://sii-herozhang.github.io/asia-capitals-handbook/>

48 个主条目与 3 个扩展条目，每个条目包含国家／地区地图、亚洲位置图、位置提示，保留中文口诀和首都自测。共 102 张网上已有地图。

## 文件

- `index.html`：静态阅读页面，支持国家／首都检索、手机布局、点击放大地图。
- `assets/`：样式和交互脚本。
- `maps/`：全部地图，滚动到相应条目时加载。
- `handbook.md`：可编辑的 Markdown 手册，与 `maps/` 配合使用。
- `map-sources.json`：逐图来源、作者、许可、获取日期和校验值；页面文末也有可读的来源表。

## 托管与更新

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 使页面作为普通静态文件提供。修改文件并推送到 `main` 后，GitHub 自动重新部署。无需安装依赖或运行构建工具。

本地预览可在仓库目录运行 `python3 -m http.server 8000` 后访问 <http://localhost:8000/>。

## 图片许可

地图保留各自原有许可，署名及许可链接见页面文末与 `map-sources.json`。SVG 使用来源站点的栅格预览，转换为 WebP 保存，未重新绘制地理内容。CC BY-SA 图片的格式转换副本沿用原许可。仓库不为整份混合来源手册统一指定图片许可。
